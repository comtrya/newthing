Workspace homepage · four directions

Same content. Same information architecture. Four different design systems.

2026-05-12 · brainstorming artifact · pick one before we write the spec

01

Operator Console

Dark, technical. Hairline borders, no shadows, no gradients. Continues the direction set by the recent ff5223f redesign — dense, ⌘K-driven, accents reserved for state.

typography: IBM Plex Sans / Mono / Serif italic density: 13px body · 9px row · 1px rules

 02

Reading Room

Light, editorial. Warm paper neutrals, Fraunces serif headlines, roman-numeral sections. Closer to a quarterly report than a dashboard; calm but still dense.

typography: Fraunces (display) · IBM Plex Sans · JetBrains Mono density: 14px body · 12px row · 1–2px rules

 03

Terminal Grid

Dark, mono-first. JetBrains Mono almost everywhere, ASCII rules separating regions, tabular alignment, terminal-color accents. Highest density of the four. Looks like a real session.

typography: JetBrains Mono everywhere · IBM Plex Sans for prose density: 12.5px body · 4–5px row · solid + dashed rules
Open mockup
 04

Mechanical Specimen

Light, brutalist edge. Bricolage Grotesque display, hairline-black rules, oversized section IDs, bordered status chips. Datasheet rhythm — typography is the structure.

typography: Bricolage Grotesque (display) · IBM Plex Sans · JetBrains Mono density: 13px body · 12px row · 1.5–2px structural rules
